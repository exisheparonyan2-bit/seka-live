# SEKA LIVE — մեկնարկային նախագիծ

Այս նախագիծը տալիս է՝
- դիտողների մուտք միայն անունով,
- իրական ժամանակի ընդհանուր չաթ,
- ադմինի հեռախոսից տեսախցիկ/խոսափող օգտագործող ուղիղ հեռարձակում,
- դիտողների համար հեռարձակման դիտում։

Սա մեկնարկային տարբերակ է։ Այն դեռ չունի ավտոմատ SEKA քարտախաղ, վիրտուալ միավորների համակարգ, ադմինի չաթի մոդերացիայի վահանակ կամ վճարումներ։

## 1. Ինչ է պետք
- Node.js 20+
- LiveKit Cloud նախագիծ (տեսանյութի ուղիղ հեռարձակման համար)
- Հոսթինգ՝ HTTPS աջակցությամբ (օր. Render)

## 2. LiveKit-ի կարգավորում
1. Ստեղծիր հաշիվ LiveKit Cloud-ում և նոր նախագիծ։
2. Պատճենիր Project URL-ը (պետք է սկսվի `wss://`-ով), API Key-ը և API Secret-ը։
3. Այս նախագծի պանակում `.env.example` ֆայլը պատճենիր որպես `.env`։
4. Լրացրու արժեքները։ `ADMIN_PASSWORD`-ի համար դիր երկար, եզակի գաղտնաբառ։
5. API Secret-ը երբեք մի տեղադրիր `public` պանակում և մի ուղարկիր ուրիշներին։

## 3. Տեղային գործարկում
```bash
npm install
npm start
```
Բացիր `http://localhost:3000`։ Տեսախցիկի/խոսափողի օգտագործման համար production կայքը պետք է HTTPS լինի։ Տեղային փորձարկման համար localhost-ը սովորաբար թույլատրվում է։

## 4. Հրապարակում Render-ում
1. Վերբեռնիր այս նախագիծը GitHub repository։
2. Render-ում ստեղծիր նոր **Web Service** և միացրու repository-ն։
3. Build command՝ `npm install`
4. Start command՝ `npm start`
5. Environment Variables բաժնում ավելացրու `.env`-ի բոլոր արժեքները։
6. Deploy արա։ Render-ի HTTPS հղումը կարող ես ուղարկել դիտողներին։

## 5. Կարևոր սահմանափակումներ և անվտանգություն
- Դիտողները մտնում են միայն անունով, ուստի անունները եզակի կամ ստուգված չեն․ մեկը կարող է ուրիշի անունն օգտագործել։
- Չաթը մեկնարկային է․ ավելացրու rate limiting, հաղորդագրությունների ֆիլտրում, արգելափակում և report գործիքներ՝ հանրային գործարկումից առաջ։
- Ադմինի գաղտնաբառը պետք է ուժեղ լինի։ Ավելի լավ է հետագայում ավելացնել իրական ադմին հաշիվ և երկփուլ պաշտպանություն։
- LIVE-ի համար օգտագործվում է LiveKit։ Հնարավոր են ծառայության սահմանաչափեր և վճարներ՝ կախված դիտողների քանակից ու հեռարձակման տևողությունից։
- Այս starter-ը նախատեսված է հեռարձակման և զրույցի համար, ոչ թե իրական դրամական խաղադրույքների կամ վճարումների։
- Բոլորի համար նույն տեսանյութն է հեռարձակվում. դիտողները քարտերը տեսնում են տեսախցիկի կադրում, երբ հեռարձակողը ցույց է տալիս դրանք։
